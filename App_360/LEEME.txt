INSTRUCCIONES RÁPIDAS DE INSTALACIÓN Y EJECUCIÓN (DOS PASOS):
========================================================================

1. SERVIDOR Y BASE DE DATOS (MySQL en XAMPP + API REST):
   a) Abrir el panel de XAMPP e iniciar los módulos "Apache" y "MySQL".
   b) Abrir una terminal en la carpeta "api":
        cd api
        npm install
        npm run crear-db
        npm run dev
   (La API quedará escuchando en http://localhost:4000/api y http://[TU_IP]:4000/api).

2. APLICACIÓN MÓVIL (React Native + Expo):
   a) Abrir otra terminal en la carpeta "mobile":
        cd mobile
        npm install
        npx expo start
   b) Opciones de visualización:
      - Presionar la tecla 'w' para abrirla en el navegador web (http://localhost:8081).
      - O escanear el código QR con la app Expo Go desde tu celular (conectado a la misma red Wi-Fi).
